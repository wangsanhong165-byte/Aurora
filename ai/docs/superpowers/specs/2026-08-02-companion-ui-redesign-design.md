# Companion UI 蓝灰工作台视觉设计说明

## 目标

将 Companion 当前的近黑、低对比界面调整为更明亮的蓝灰工作台风格，吸收 Claude / Codex 的克制、清晰和留白原则，同时保留 Live2D 舞台和角色的粉紫、青蓝视觉个性。

## 范围

- 调整前端工作区的颜色层级、间距、圆角、边框和状态样式。
- 统一左侧导航、右侧抽屉、聊天记录和底部聊天输入区。
- 统一工作区内的 Lucide 图标尺寸、线宽、容器和状态。
- 不改变 Runtime、协议、历史记录命令、Live2D 控制链或后端服务。

## 视觉决策

- 使用蓝灰色背景与分层表面，避免纯黑和过密边框。
- 提高主文字和次要文字对比度，让信息层级更清楚。
- 使用低饱和淡紫、冰蓝和柔和粉色作为强调色，避免大面积高饱和色。
- 输入区保持轻微通透和悬浮感，但不遮挡角色主体。
- 右侧抽屉作为工作区的一部分，而不是独立的黑色侧栏。
- 激活态依靠表面、明度和小面积强调色表达，不使用厚重色块。

## 图标规则

- 工作区统一使用 `lucide-react`。
- 一级导航图标 18px，普通操作 16px，紧凑操作 14px。
- 统一约 1.75 的 stroke width，并保持相同的居中和按钮容器。
- 用 `X`、`MessageSquare`、`ChevronLeft`/`ChevronRight`、`Plus` 替换字符和 emoji 图标。
- 默认、悬停、激活、危险状态使用统一的颜色语义。

## 验收标准

- 角色主体不再被近黑 UI 压暗。
- 左侧导航、右侧抽屉、历史记录、输入区具有一致的层级和留白。
- 工作区内不存在混用字符、emoji 和 Lucide 图标造成的视觉断层。
- 抽屉展开、收起、调整宽度，以及历史记录新建、加载、删除行为保持不变。
- 真实 Electron/browser 页面在常规和窄窗口下均可读、可操作。
