# 完整提示词来源控制实现计划

**目标：** 将仅能追加内容的半成品升级为按角色控制 system 来源的完整配置页，并把用户输入所在的真实请求审计拆到独立页面。

## 已完成

- [x] 新增 `PromptConfigStore`，按角色持久化来源的默认、替换、关闭模式。
- [x] `DefaultPlanner` 在真实消息组装时解析来源策略；动态记忆和状态同样可关闭或替换。
- [x] 输出协议保持只读，避免破坏结构化回复、动作和语音链路。
- [x] 管理动作显式携带角色 ID，消除切换期间写错角色的竞态。
- [x] `get_prompt_view` 只返回请求角色自己的快照，并给消息附加来源身份用于 UI 分类。
- [x] 前端拆分“提示词配置”和“请求记录”；配置页不再展示用户输入。
- [x] 角色切换自动加载对应配置；未保存草稿按角色暂存。
- [x] 支持单项恢复默认和“全部恢复默认”，附加提示词留空即移除。
- [x] 真实 V3 WebSocket 验证关闭来源后实际请求减少，恢复默认后来源重新出现。
- [x] 测试结束后将 Monika 配置恢复为全部默认且附加内容为空。
